# bot-console

QQ 机器人的**远程配置台**：一个零依赖的本地网页服务，用来改人设、改白名单、开关功能、看运行状态。

不是机器人本体——机器人仍然跑在 DSH（DeepSeek Harness）里；这个工具只负责**改它的配置文件**。

## 现在能做什么

| 能力 | 说明 |
|---|---|
| 看状态 | OneBot 端口是否在监听、QQ 账号是否在线、配置文件是否可解析 |
| 改人设 | 直接编辑 Markdown 人设文件并保存（下一条消息生效） |
| 改白名单 | 私聊白名单、群白名单、管理员、通知接收人、可插话的群 |
| 开关功能 | 人格开关、主动说话、好友申请自动通过 / 转人工审批、正在输入、戳回去 |
| 调参数 | 主动说话间隔与上限、群聊插话概率与上限、气泡字数与条数 |
| 换模型 | 机器人独立的 provider / model 通道 |
| 手动重载 | 改完配置让它立刻重新加载 |

## 快速开始

```bash
# 1. 复制一份配置，按自己的路径改
copy config.example.json config.json

# 2. 启动
node src/server.mjs
# 或
npm start
```

首次启动会生成 `.token` 文件，控制台里会打印带 token 的地址：

```
bot-console 已启动
  地址: http://127.0.0.1:8787/?token=xxxxxxxx
```

浏览器打开那个地址即可。**token 丢了就重新打开控制台看**，或者删掉 `.token` 重启生成新的。

## 配置项从哪来

```
web/index.html          界面（单页，无构建）
src/server.mjs          服务端（Node 内置模块，零 npm 依赖）
config.json             本机配置（路径、端口、OneBot 地址）——不进 git
.token                  访问令牌——不进 git
```

服务端只读写两处：

- `profileDir/cordis.patch.yml` —— 机器人的配置覆盖行（保存后 DSH 会自动重载）
- `pluginDir/persona.md` —— 人设文件

写文件用的是「临时文件 + 原子替换」，不会出现写一半把配置弄坏的情况；保存前也会校验允许修改的字段和类型。

## 安全

- 默认只绑定 `127.0.0.1`，外网访问不到；
- 所有请求都要带 token（`?token=` 或 `x-token` 头）；
- 只能改白名单里列出的配置项，不能改任意字段。

要在别的机器上访问，推荐 SSH 隧道，而不是把端口暴露到公网：

```bash
ssh -L 8787:127.0.0.1:8787 user@server
```
