# 表情包图库

这里放机器人能发的表情包。**子目录名就是标签**，文件放进去就能用，不用改代码、不用重启（每次发图时重新扫描目录）。

```
stickers/
  开心/   1.png  2.gif  ...
  无语/   ...
  困/     ...
  摸摸/   ...
```

- 支持的格式：`.gif` `.png` `.jpg` `.jpeg` `.webp`
- 单张上限 8 MB（超过会被跳过）
- 标签名随便起，中文英文都行；建议用情绪/场景词，方便模型挑

## 怎么用

| 场景 | 操作 |
|---|---|
| 手动发一张 | 群里或私聊发 `/sticker 开心` |
| 看有哪些标签 | 发 `/sticker` |
| 让模型自己挑 | 它有个 `qq_sticker` 工具，聊天时会自己决定发不发 |
| 自动补表情 | 配置里把 `stickerAutoChance` 调成 `0.1`（10% 概率在回复后补一张），默认 0 关闭 |

## 定制

1. **加图**：直接把图片丢进对应标签目录；想加新标签就新建目录。
2. **换目录**：配置项 `stickerDir` 指到别处（比如网络盘、用户自己的图库目录）。
3. **给最终用户用**：部署时把这个目录做成可写位置（或让用户在配置台里改 `stickerDir`），他们自己往里放图即可，机器人自动识别。

## 注意

- 图太大会拖慢发送，建议单张 < 500 KB、尺寸不超过 800×800；
- GIF 动图支持，但部分客户端会压缩；
- 这个目录里不要放非图片文件，会被忽略。
